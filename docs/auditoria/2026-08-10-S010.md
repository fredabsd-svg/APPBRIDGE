   - UpdateApplicationDto: DisplayName, Description, IconUrl

   - Implementa IApplicationService com multi-tenant isolation (TenantId filtering, DeletedAt==null checks)
   - ListUserApplicationsAsync delegada para IAuthorizationService.GetUserApplicationsAsync (autorização e permissões)
   - Soft-delete via DeletedAt
   - Logging em Information/Warning
   - Conversão de entity para DTO via MapToDto privado

4. **src/AppBridge.ControlPlane/Api/Controllers/ApplicationsController.cs**
   - [Authorize] [Route("api/applications")] controller
   - Validação de tenant/user context via ITenantContextService em cada endpoint
   - GET /api/applications → ListUserApplicationsAsync
   - GET /api/applications/{applicationId} → GetApplicationAsync
   - POST /api/applications → CreateApplicationAsync (valida Identifier, DisplayName, RemoteAppName, retorna 201 CreatedAtAction)
   - PUT /api/applications/{applicationId} → UpdateApplicationAsync (valida DisplayName, trata KeyNotFoundException→404)
   - PATCH /api/applications/{applicationId}/publish → PublishApplicationAsync
   - DELETE /api/applications/{applicationId} → DeleteApplicationAsync (retorna 204 NoContent)

5. **tests/AppBridge.ControlPlane.Tests/Services/Applications/ApplicationServiceTests.cs**
   - 10 métodos de teste usando IAsyncLifetime, InMemory DbContext, mock de IAuthorizationService

6. **tests/AppBridge.ControlPlane.Tests/Api/Controllers/ApplicationsControllerTests.cs**

   - Testa: status codes (200/201/204/400/401/404), context validation (TenantId/UserId), payload validation, routing
